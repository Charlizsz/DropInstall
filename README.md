# DropInstall

独立的 macOS DMG / ISO 批量安装工具。通过 Finder 服务或拖入文件，完成查重、安装、弹出磁盘与成功后的安装包清理。

支持 macOS 14+、Apple Silicon 与 Intel；使用 Swift 6 和原生 SwiftUI / AppKit，无第三方依赖。

## 使用

1. 将 `dist/DropInstall.app` 放进「应用程序」，打开一次。
2. 在 Finder 选择一个或多个 `.dmg` 或 `.iso`，右键 → **服务 → 安装 DMG 到应用程序**。
3. 安装队列自动开始：挂载 → 查找并先检查重名 → 安装非重名应用 → 弹出磁盘。重名项先记为待定，确认前不复制完整应用。
4. 队列结束后统一询问是否批量覆盖。可选「批量覆盖」「全部保留现有版本」或「稍后决定」；稍后可点击「处理 N 个重名」重新打开汇总窗口。
5. 同一 DMG 内的应用全部安装或覆盖成功、且磁盘已弹出后，DMG 自动移入废纸篓，需要时可以恢复。

也可以将多个 DMG 或 ISO 拖进 App 窗口，点击「安装」。ISO 一加入队列就自动在原文件夹改为 `.dmg` 后缀，无需确认，也不重新生成映像内容；`.ISO` 同样识别。已有同名 `.dmg` 时依次使用 `名称 (2).dmg`、`名称 (3).dmg`，不会覆盖已有文件。队列显示改名前后的名称，后续覆盖确认、弹出和成功后移入废纸篓都使用新的 DMG 路径。失败时保留已改名的文件；已挂载、无权限或不可改名的 ISO 会显示错误，可解决后重试。

默认安装位置为 `/Applications`；没有写入权限时，可在窗口切换到「仅我使用」，安装到 `~/Applications`。服务沿用窗口最后选定的位置。

App 未运行时也支持 `open -a DropInstall --args --enqueue /path/one.dmg /path/two.dmg` 将文件加入待安装队列。该入口不自动安装；路径包含空格时需加引号。

如果服务菜单没有出现，在 **系统设置 → 键盘 → 键盘快捷键 → 服务** 中启用该项目；系统可能需要重新登录才刷新。服务仅接收 Finder 传入的磁盘映像，程序在启动时注册服务提供者。

## 内层 DMG 查找规则

在安装位置旁点击「查找规则…」，可以添加、停用、删除多条规则，保存后重启仍有效。每条规则包含「文件夹名称」和「DMG 文件名称」。默认启用 **`Manual Install` → `*.dmg`**，因此 `Manual install` 的小写写法也能匹配。

名称匹配不区分大小写；`*` 匹配任意字符，`?` 匹配单个字符，其他字符按字面匹配。规则针对单个名称，不接受完整路径。例如文件夹 `Manual*` 搭配文件名 `Noir*.dmg` 可以匹配该目录中的 Noir 映像。多条规则命中同一 DMG 时只处理一次；关闭或删除全部规则后仍可安装普通 DMG 中的 `.app`。

外层挂载 → 找到规则命中的文件夹和内层 DMG → 挂载内层并安装应用 → 先弹出内层、再弹出外层。默认规则可处理 `外层.dmg / Manual install / 内层.dmg / App.app`。每层在根目录及两层普通包装目录中查找规则文件夹，再在匹配目录及其两层子目录中查找 DMG；不跟随符号链接，不进入应用或安装包内部。最多处理 3 层（包含最外层）、16 个映像，超限会保留源 DMG 并提示。

整个外层任务沿用同一批次的规则快照。重名应用仍统一待确认，所有内层及外层均处理成功后，仅最外层下载的 DMG 移入废纸篓。任意内层失败时保留外层。只查找 DMG 和复制 `.app`，不会执行随附脚本或说明文件里的命令；安装的应用继承最外层下载文件的隔离标记。

## 0.6 的行为范围

- 支持普通 DMG 内可拖拽安装的 `.app`，包括根目录及最多两层包装目录中的多个应用。
- 同名应用先待定，确认前不复制新版、现有应用不变。确认后按原 DMG 分组重新挂载，只复制获准覆盖的应用，再整包原子交换；旧版移入废纸篓，不合并新旧文件。移入废纸篓失败时保留旧版备份，并显示路径。
- 正在运行的应用保持待定，退出该应用后再确认；DropInstall 自身需退出后用 Finder 手动更新。目标在待定期间被替换或顶层目录被修改时拒绝覆盖，需重新添加 DMG。
- 待定项只记录来源、映像内路径和目标状态，通常不占用应用复制空间。确认时重新检查原 DMG 与现有应用是否变化；复制前及覆盖前检查应用是否正在运行。选择保留现有版本或退出时取消待定项、保留原应用和未获批准的 DMG，不再弹出退出确认，不跨重启保存队列。若目标在初次复制期间新出现重名，已复制的副本仍暂存至确认或退出。
- 成功安装或覆盖的 DMG 自动移入废纸篓。待确认、放弃覆盖、部分失败、弹出失败的 DMG 保留；待定期间原文件被替换或重新挂载时也保留。移动失败显示提示，不永久删除文件。
- 挂载沿用 macOS 默认完整性校验，不添加 `-noverify`，不绕过 Gatekeeper。0.5 通过复制前查重、同一 DMG 合并覆盖、复用挂载返回的卷信息以及进程完成事件通知减少等待。首次挂载和大文件实际复制仍可能较慢；选择覆盖时会重新挂载读取，不能把预检节省的时间理解为所有安装都能同幅度加速。
- 不自动打开新装应用；保留扩展属性和下载隔离标记，由 macOS 在首次打开时执行正常安全检查。
- `.pkg`、密码保护或需要交互同意许可的 DMG、专用安装器不自动执行。
- 已挂载的 DMG 提示先弹出后重试；只清理本次挂载，不强制弹出。弹出失败会显示磁盘位置。
- 批次顺序执行，单项失败不阻止后续任务。「停止队列」在当前项目完成并尝试弹出后停止。
- 点击红色关闭按钮、菜单「退出」或 Command-Q 都会退出 App。空闲时立即结束；安装中窗口及 Dock 运行图标立即隐藏，停止后续队列，当前项目收尾后自动结束，无需再次退出。强制结束进程或系统断电可能留下挂载磁盘或隐藏的临时复制目录，需手动检查。
- 本地构建使用 ad-hoc 签名，未作 Developer ID 公证，不能视为面向公众分发的正式安装包。

0.5 的同包重复打开测试及适用范围见 [PERFORMANCE.md](PERFORMANCE.md)。

## 构建与测试

macOS 14+，Swift 6 工具链（Xcode 或 Command Line Tools）。无需安装完整 Xcode。克隆本仓库后，在项目根目录运行：

```sh
bash scripts/build.sh
bash scripts/test.sh
```

构建产生 Intel + Apple Silicon 通用的 `dist/DropInstall.app` 和 ZIP。脚本检测到旧 Command Line Tools 重复的 SwiftBridging 模块映射时，只对本次编译应用虚拟文件系统映射，不修改系统工具链。

测试创建临时 DMG 和应用包，在临时安装目录验证实际挂载、批量复制、弹出、重名待定、确认覆盖、旧版回收、放弃覆盖、目标变更保护、队列结束统一询问、成功后 DMG 回收、失败和未批准 DMG 保留、空闲及安装中退出、隔离属性、损坏映像、无 `.app`、无效应用包、预先挂载保护及服务输入。另验证多条通配规则、设置持久化、两层及三层映像、超限保护、嵌套损坏、重名覆盖、外层隔离属性传播及内外层清理。不会执行测试应用或写入 `/Applications`。

本机可以只用 Apple Command Line Tools 提供的 Swift 编译器及 macOS SDK 构建，无需安装完整 Xcode。通用二进制在本机分别编译 arm64 和 x86_64 后合并；Intel 版本完成交叉编译，不代表已经在 Intel Mac 上实机测试。

`Sources/Installer.swift` 是独立安装核心，`SearchRules.swift` 定义规则及持久化，`RulesEditor.swift` 提供编辑界面；`AppModel.swift` 管理队列及系统服务，`InstallerView.swift` 是 SwiftUI 主界面，`Main.swift` 管理 AppKit 生命周期。系统进程只通过固定可执行文件和参数数组调用，不拼接 shell 命令。
